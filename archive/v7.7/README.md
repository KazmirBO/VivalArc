# Archive — Vivaldi 7.7 Variants

These folders contain the legacy variant stylesheets last updated for Vivaldi 7.7.

| Folder | Description |
|--------|-------------|
| `autotab/` | Auto-hiding tab bar (v1.2.0). The auto-hide feature has since been integrated into the root `vivalarc.css` as an optional toggle (`--enable-autohide-tabbar: 1`). |
| `compact/` | Compact UI spacing (v1.2.0). Kept for reference only. |

These files are not maintained. For current installs, use `vivalarc.css` in the repository root.
