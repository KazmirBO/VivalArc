# Jak używać lokalnych motywów Vivaldi

W folderze projektu VivalArc umieściłem kilka plików motywów Vivaldi. Motywy te zostały również wysłane do społeczności Vivaldi, jednak część z nich wciąż czeka na zatwierdzenie i na razie nie można ich zainstalować bezpośrednio ze strony społeczności. Jeśli chcesz używać tych motywów lokalnie, obejrzyj poniższy film, aby dowiedzieć się, jak je skonfigurować.
